# Seed vocabulary

- Guardian: immutable Rust evaluator (daemon, gates, promotion). Never evolvable.
- Organism: evolvable TS/Python harness (loop, router, capabilities, lab).
- Lab: evolution machinery (friction, governor, scientist, GEPA, challenges).
- Champion: current production ref. Candidate: proposed ref. Archive: kept non-champions.
- Capability: versioned package (manifest + entrypoint + tools + permissions).
- Friction: deterministic rule hit over telemetry (repeat, error, search, compile-loop, recovery, ephemeral, correction, waste, latency).
- Oracle: executable pass/fail script per eval task. Smoke: 2-task fail-then-pass contract check.
